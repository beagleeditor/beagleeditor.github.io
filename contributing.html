Contributing to BeagleEditor

Help improve BeagleEditor by contributing code, documentation, plugins, and ideas.

Getting Started

  1. Fork the repository.
  2. Clone your fork.
  3. Create a new branch.
  4. Make your changes.
  5. Open a pull request.

Ways to Contribute

  • 🐛 Report bugs
  • ✨ Suggest features
  • 💻 Improve code
  • 📚 Improve documentation
  • 🧩 Create plugins
