Welcome to BeagleEditor

BeagleEditor is a desktop code editor built with React, Monaco Editor, Rust, and Tauri 2. Use these guides to learn the interface, configure the editor, and extend it.

Need help?

If a feature behaves differently than documented, first check the version you're running and consult Troubleshooting. When reporting a bug, include your operating system, BeagleEditor version, reproducible steps, and relevant error output. Remove private paths, credentials, and source code you don't want to share.
