TOOLING STATUS

Command-line tools

BeagleEditor is currently a desktop editor. The former standalone CLI is discontinued; the desktop app includes an integrated terminal for running your normal development tools.

Compatibility note: Do not rely on old standalone CLI commands or assume they are included with current desktop releases.

Use the integrated terminal

Open the Terminal panel to run your shell, build tools, Git, language servers, and other command-line programs in the context of your workspace. Terminal sessions use your configured system shell and run with your user permissions.

Read the terminal guide →

What happened to the old CLI?

The earlier terminal-based editor was discontinued. Its commands and behavior are not part of the current desktop app's supported interface.

Is a new standalone CLI available?

This website does not currently document a supported standalone BeagleEditor CLI release. Check the official releases for the current downloadable application and release notes.
