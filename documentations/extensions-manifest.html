Manifest reference

3. Extension manifest

Create manifest.json:

{
  "id": "word-counter",
  "name": "Word Counter",
  "version": "1.0.0",
  "description": "Counts words in the active document.",
  "main": "main.js"
}

Fields:

FieldRequiredMeaning
idYesStable extension identifier. Use a unique, simple ID such as word-counter. It prefixes command IDs.
nameYesHuman-readable name shown in the Extensions view and command categories.
versionYesVersion string displayed by the UI, for example 1.0.0.
descriptionNoShort description displayed in the Extensions view.
mainNoEntry filename. Defaults to main.js. The entry file must be directly inside the extension folder.
typeNoSet to "theme" for a JSON-only color theme. Omit it for a JavaScript extension.
themeTheme onlyTheme data filename. Defaults to theme.json; the file must be directly inside the extension folder.

The manifest must be valid JSON. BeagleEditor skips folders with missing or invalid manifests, blank required fields, invalid IDs, duplicate IDs, or missing/unreadable entry files. Extension IDs may contain ASCII letters, numbers, dots, hyphens, and underscores. Use a unique id for every extension; command IDs are prefixed with it.
