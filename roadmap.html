Roadmap

Where BeagleEditor is today—and where we want to take it next. Priorities may change as the project evolves.

Available now

  • Workspace Explorer, file operations, and multi-tab editing
  • Quick Open and command palette
  • Session restoration and recent workspaces
  • Markdown preview with synchronized scrolling
  • Integrated terminal, search, Git, and Problems panels
  • Language-server diagnostics, completion, navigation, and formatting
  • JavaScript extensions and installable JSON color themes
  • Run and debug workflows

Near-term priorities

  • Make extension discovery, installation, and management smoother
  • Improve reliability and responsiveness in larger workspaces
  • Refine terminal, Git, and debugging workflows
  • Broaden language-server guidance and compatibility testing
  • Polish keyboard navigation, accessibility, and small-screen layouts

Longer-term direction

  • More useful workspace-wide navigation and code intelligence
  • A clearer, more capable extension ecosystem with better discovery and documentation
  • More flexible editor customization and workspace preferences
  • Consistent packaging and release experience across Windows, macOS, and Linux

This roadmap describes current direction, not guaranteed release dates. Follow development and report issues on GitHub.
